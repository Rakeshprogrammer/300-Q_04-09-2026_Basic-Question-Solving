## 💻 My Approach

For every problem, my goal is to follow this process:

```text
Understand the Problem
        ↓
Think About the Logic
        ↓
Try to Solve It Myself
        ↓
Write the Code
        ↓
Test the Solution
        ↓
Analyze & Improve
```

I’m focusing on understanding **why** a solution works, not just **what** the solution is.
